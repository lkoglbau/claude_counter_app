## Fehler und Lösungen

1. **Löschen in der Detailansicht ging nicht.** Es gab drei Ursachen:
   - `Alert.alert` tut auf Web nichts, der Lösch-Callback feuerte nie.
   - Es wurde doppelt zurücknavigiert.
   - Supabase meldete ein von RLS blockiertes Delete als Erfolg mit 0 Zeilen.

   Jetzt nutzen beide Lösch-Wege dieselbe Hilfsfunktion `confirmDestructive`. Es wird erst gespeichert und danach genau einmal navigiert. 0 gelöschte Zeilen gelten als Fehler und werden angezeigt.
2. **Weißer Bildschirm auf der Vercel-Preview.** Die Supabase-Variablen waren nur für Production gesetzt. Der Preview-Build hatte sie nicht, und `supabaseClient.ts` wirft dann beim Import. Die Variablen wurden auch für Preview angelegt und neu deployt.
3. **Kein Kalender im Datumsfeld auf Web.** Das Paket `@react-native-community/datetimepicker` hat keine Web-Implementierung. Auf Web nutzt `DateField` jetzt ein natives `<input type="date">`.
4. **Ausrutscher speichern schlug fehl.** Die Migration hatte der Tabelle `slips` keine Grundrechte für `authenticated` gegeben („permission denied“). Die Rechte wurden per Migration nachgereicht.
5. **Datumsfeld: falsche Schrift und Datum rechts.** Der Browser-Input nutzte eine eigene Schrift. Er erbt jetzt die App-Schrift, und das Datum steht links.
